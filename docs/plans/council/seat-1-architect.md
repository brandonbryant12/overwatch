2. **Storage and state**
Keep minimal event sourcing: append-only `events` committed in the **same synchronous `BEGIN IMMEDIATE` transaction** as `STRICT` relational tables in `overwatch-v2.sqlite` (`DatabaseSync`). Delete `objects`, `alarms`, `pending_reports`, `projections`, `revisions_seen`, `code_worktrees`, `session_reads`, and `search_terms`. Twelve tables: `meta(key PK,val)`; `events(seq INTEGER PRIMARY KEY AUTOINCREMENT,at_ms,kind,entity,actor,data_json)`; `incidents(id PK,app,env,tier,source,fingerprint,title,severity,sample,query,total_count,last_seq,way,way_seq,way_until_ms,way_waits,base_sev,base_rate,since_way,back_reason,seen_seq,UNIQUE(app,env,fingerprint))`; `occurrences(incident_id,occ_key,at_ms,PK(incident_id,occ_key)) WITHOUT ROWID`; `sources(watcher,source,checkpoint_ms,last_ok_ms,every_ms,conn_key,fail_kind,streak,next_at_ms,suspended_ms,last_err,fix_cmd,rev_sha,PK(watcher,source))`; `metrics(watcher,source,metric,poll_seq,at_ms,val,limit_val,PK(watcher,source,metric,poll_seq)) WITHOUT ROWID`; `deploys(seq PK,app,env,rev_sha,prev_sha,at_ms)`; `threads(id PK,incident_id UNIQUE,handoff_json)`; `runs(id PK,thread_id,incident_id,session_id,msg_id,token_hash UNIQUE,status,commit_sha,commit_deployed,created_seq,sent_ms,attempts,error)`; `spans(span_id PK,run_id,kind,source_ref,content)`; `outbox(id PK,kind,target_id,payload_json,status,attempts,next_ms)`; `search_fts` (FTS5, `LIKE` fallback). Every change is one synchronous `mutate(tx => ...)`: zero interleaving, zero view lag, full audit/replay in `events` (cost: ~2× row writes, 1–20 ms lock). `WriteTx` accepts only numbers, `ScrubbedText` (minted solely by `scrub()`), and `OpaqueId` (RNG or `sha256(clientId)`), blocking unredacted text and raw caller IDs by construction (cost: hashed client IDs).

3. **Counting occurrences**
Delete [signals.ts](/Users/brandon/Development/overwatch/src/collect/signals.ts)'s 500-ID `SeenEntry.recent`, `pending_reports`, and `Math.max(...array)` spreads. Stream `kubectl logs` line-by-line with scalar `minAt`/`maxAt`. Key each occurrence deterministically: `dd:<id>`, `k8se:<uid>:<count>`, `k8st:<pod>:<container>:<finishedAt>`, or `k8sl:<pod>:<container>:<rfc3339nano_ts>:<dup_ordinal>:<sha256_8(line)>` (ongoing breaches: `poll:<floor(now/everyMs)>`). One transaction runs `INSERT OR IGNORE INTO occurrences`, adds `changes` to `incidents.total_count`, appends `SignalRecorded`, advances `sources.checkpoint_ms`, and prunes `occurrences WHERE at_ms < checkpoint_ms - overlap_ms`. Primary-key uniqueness guarantees exact counts across crash, replay, and overlap late data (cost: ~4 MB B-tree churn per 50k storm).

4. **Order and time**
`events.seq` is the **only** decision clock; `at_ms` drives external deadlines (`way_until_ms`, `next_at_ms`) and display. Delete `bringBackOnDeploy` ([service.ts](/Users/brandon/Development/overwatch/src/service/service.ts)). Deferring sets `way='later', way_seq=seq`. Deploys append `DeployObserved` (`deploy_seq=seq`) and run inline: `UPDATE incidents SET way='inbox', back_reason=... WHERE app=? AND env=? AND way='later' AND way_waits='change' AND way_seq < :deploy_seq RETURNING id`, logging `IncidentCameBack` only for returned IDs—total order, zero millisecond ties, zero `O(history)` receipts (cost: serialized writes). Server `seen_seq = max(seen_seq, ?)` stops two-tab clobbering.

5. **One writer, upgrade, backup and restore**
Delete [lock.ts](/Users/brandon/Development/overwatch/src/host/lock.ts) and `.writer`/`.holder`/`.lock` sidecars. Before binding `127.0.0.1:7450`, run `PRAGMA busy_timeout=0; PRAGMA journal_mode=WAL; PRAGMA locking_mode=EXCLUSIVE; BEGIN EXCLUSIVE; COMMIT;` on `overwatch-v2.sqlite`. SQLite holds the OS kernel lock until exit or `SIGKILL`, blocking competing starts and cross-version writers by construction (cost: live CLI calls loopback HTTP). `upgrade` runs `launchctl bootout`, applies additive `user_version` migrations under that lock, then `bootstrap`s. Delete `validateBackup` ([backup.ts](/Users/brandon/Development/overwatch/src/service/backup.ts)): `backup` exports a SHA-256-signed `.owbak` JSONL snapshot; `restore` populates a **fresh** `SCHEMA_SQL` DB via `WriteTx` and `renameSync`s it in—foreign DDL, triggers, and hidden `UNIQUE` autoindexes cannot enter (cost: ~80 ms parse).

6. **Evidence**
Delete `verifyCitations` ([citations.ts](/Users/brandon/Development/overwatch/src/collect/citations.ts)) and model `confidence`. Every sample, `query_telemetry`, `read_code`, and `git_history` line/hunk enters `spans(span_id, run_id, kind, source_ref, content)` (`'telemetry'|'code'|'git'`), shown as `[S14 | telemetry:k8s] ...`. Prompts, summaries, and query arguments mint **no** spans. `file_finding` accepts `spanIds: string[]`—no `quote` or `source` inputs exist. Overwatch copies quotes and provenance from `spans`; `real` + `observed` requires >=1 `'telemetry'` span or downgrades to `inferred` (guarantee: zero hallucinated, elided, or spoofed quotes; cost: line granularity, ~20 KB/run).

11. **Declared operating limits**
- **Topology**: <=50 watchers, <=4 sources/watcher, `every >= 60s` (`overwatch check` refuses above).
- **Burst**: <=50,000 occurrences/slice, <=16 MiB subprocess stdout, <=5,000 Datadog logs/slice; beyond cap, commits exact count through `t_cut`, flags `50,000+ (capped)`, logs source `gap`.
- **Overlap/sleep**: 5m overlap (`occurrences` <=250,000 rows / 24h; >5m late data ignored with counter); <=6h lookback (older becomes `gap`; wake investigations capped at 3 prod, rest `held`).
- **Agents/DB**: <=2 concurrent runs, <=8 tool calls, 5m timeout, 1 retry then `parked`; `events` compacted at 500,000 rows / 90d to `.jsonl.gz`.
